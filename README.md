# CSS Generator

A comprehensive tool designed to generate custom CSS code dynamically, streamlining the styling workflow for web developers.

## Overview

CSS Generator is a project built to simplify CSS creation through an intuitive interface. This tool enables developers to generate production-ready CSS without manual coding, reducing development time and minimizing syntax errors.

## Technologies Used

**Frontend:**
- HTML5, CSS3, JavaScript (ES6+)
- Responsive design with modern CSS patterns
- Async/await for seamless API communication
- DOM manipulation for real-time code preview

**Backend:**
- Node.js with Fastify framework (lightweight, high-performance)
- RESTful API architecture with CORS support
- Environment configuration management (dotenv)

**AI Integration:**
- Groq AI API integration (Llama 3.3-70B language model)
- Natural language processing for design-to-code conversion
- Intelligent prompt engineering for consistent output

**Deployment & Tools:**
- Version control: Git & GitHub
- Cloud deployment on Render

## Key Features

⚡ **Real-time AI-powered CSS generation** — Instantly convert design descriptions to code  
🎯 **Production-ready output** — Clean, optimized HTML and CSS  
🚀 **Full-stack implementation** — Demonstrates backend API integration and frontend-backend communication  
📱 **Responsive & intuitive UI** — Minimalist design focused on user experience  
🔄 **Live preview** — See your generated designs rendered in real-time

## Technical Highlights

- Asynchronous API handling with error management
- RESTful endpoint design (`/generate-css`)
